Soporte de EVAText

Ayuda para el complemento de retroalimentación académica de Microsoft Word.

¿Qué es EVAText?

EVAText es un complemento para Microsoft Word que permite insertar comentarios de retroalimentación académica sobre palabras, oraciones o fragmentos seleccionados.

Cómo usar EVAText

  1. Abre un documento de Word.
  2. Entra en la pestaña EVAText.
  3. Pulsa Abrir EVAText.
  4. Selecciona un fragmento del documento.
  5. Busca el comentario que necesitas.
  6. Pulsa Insertar comentario.

Problemas frecuentes

El comentario no se inserta

Comprueba que hayas seleccionado una palabra, oración o fragmento antes de pulsar el botón.

El panel no abre

Verifica que tengas conexión a Internet. Cierra Word completamente, vuelve a abrirlo e intenta nuevamente.

No aparece la pestaña EVAText

Revisa que el complemento esté instalado en Mis complementos. Algunas cuentas institucionales restringen la instalación de complementos personalizados.

Aparece una dirección localhost

Esto significa que se instaló un manifiesto de desarrollo. Usa el manifiesto de producción publicado con EVAText.

Compatibilidad

EVAText está diseñado para funcionar en:

  • Word para Windows.
  • Word para la web.
  • Word para Mac compatible con las API utilizadas.

Solicitar ayuda o informar un error

Puedes informar errores, solicitar mejoras o formular preguntas desde el repositorio oficial.

Informar un problema

Información útil para informar un problema

Incluye, cuando sea posible:

  • Versión de Word.
  • Sistema operativo: Windows, macOS o navegador.
  • Navegador utilizado.
  • Descripción de lo que estabas haciendo.
  • Mensaje de error o captura de pantalla.
  • Nombre del comentario que intentabas insertar.

Privacidad

EVAText utiliza permisos de lectura y escritura del documento para insertar comentarios. El complemento no está diseñado para recopilar ni enviar el contenido de los documentos a servicios externos.
