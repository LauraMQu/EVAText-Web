Política de privacidad de EVAText

Última actualización: 30 de julio de 2026

Resumen: EVAText no está diseñado para recopilar, almacenar, vender ni compartir datos personales ni el contenido de los documentos de Microsoft Word.

1. Responsable del complemento

EVAText es un complemento para Microsoft Word mantenido por LauraMQu.

Repositorio oficial: github.com/LauraMQu/EVAText-Web

2. Finalidad de EVAText

EVAText permite insertar comentarios de retroalimentación académica sobre palabras, oraciones o fragmentos seleccionados en documentos de Microsoft Word.

3. Información que EVAText procesa

Para ejecutar su función, EVAText accede temporalmente al fragmento que la persona selecciona dentro del documento de Word.

Este acceso se utiliza únicamente para comprobar que existe una selección y para insertar en ella el comentario elegido.

EVAText no está diseñado para recopilar ni almacenar:

  • El contenido completo de los documentos.
  • Los fragmentos seleccionados.
  • Los comentarios insertados.
  • Nombres, direcciones, teléfonos o documentos de identidad.
  • Credenciales de Microsoft.
  • Contraseñas.
  • Datos financieros.
  • Información de ubicación precisa.

4. Uso de la información

El contenido seleccionado se procesa localmente dentro del entorno de Microsoft Word mediante Office.js.

EVAText utiliza esa selección únicamente para:

  • Comprobar que la persona haya seleccionado texto.
  • Insertar el comentario de retroalimentación elegido.

El complemento no utiliza el contenido del documento para publicidad, elaboración de perfiles, análisis comercial ni toma automatizada de decisiones.

5. Almacenamiento de datos

EVAText no utiliza actualmente una base de datos ni un servidor propio para almacenar información personal o contenido de documentos.

Los comentarios insertados forman parte del documento de Word y quedan sujetos al almacenamiento y a las configuraciones de Microsoft 365, OneDrive, SharePoint o del dispositivo de la persona usuaria.

6. Transferencia o divulgación de información

EVAText no vende, alquila ni comparte información personal con anunciantes, intermediarios de datos u otras empresas.

El complemento no envía el contenido del documento a servicios externos controlados por EVAText.

7. Servicios externos

Los archivos públicos necesarios para ejecutar el complemento se alojan mediante GitHub Pages.

Microsoft Word y Microsoft 365 son servicios proporcionados por Microsoft y se rigen por sus propias políticas, términos y controles de privacidad.

GitHub y GitHub Pages son servicios proporcionados por GitHub y se rigen por sus propias políticas y condiciones.

8. Permisos solicitados

El manifiesto de EVAText solicita el permiso ReadWriteDocument.

Este permiso es necesario para leer temporalmente la selección activa y agregar un comentario al documento.

EVAText no utiliza este permiso para copiar ni conservar el contenido del documento fuera de Word.

9. Cookies y tecnologías de seguimiento

EVAText no incorpora actualmente cookies propias, herramientas publicitarias, sistemas de seguimiento ni servicios de analítica.

Los servicios de Microsoft o GitHub pueden aplicar sus propias tecnologías técnicas de acuerdo con sus respectivas políticas.

10. Seguridad

EVAText se distribuye mediante conexiones HTTPS y no requiere ejecutar un instalador local.

Aunque se adoptan medidas razonables para mantener el código y los recursos seguros, ningún sistema informático puede garantizar una seguridad absoluta.

11. Personas menores de edad

EVAText no está diseñado para recopilar conscientemente información personal de menores de edad.

Su uso en contextos educativos debe realizarse conforme a las reglas de la institución y bajo la supervisión correspondiente cuando sea necesario.

12. Derechos de las personas usuarias

Como EVAText no almacena directamente información personal ni contenido de documentos, normalmente no existe una base de datos propia desde la cual consultar, corregir o eliminar datos.

Las solicitudes relacionadas con información almacenada en Microsoft 365, Word, OneDrive o SharePoint deben gestionarse mediante las herramientas y políticas de Microsoft o de la organización responsable de la cuenta.

13. Cambios en esta política

Esta política podrá actualizarse cuando cambien las funciones de EVAText, sus servicios asociados o los requisitos legales y de publicación.

La fecha de la última actualización se indicará al comienzo de esta página.
